# 智能待办 · 待办提醒 App (Smart Todo Reminder)

基于**时间 + 地理位置**的智能待办提醒 Android 原生应用。根据实时位置与交通状况，自动推算“最晚出发时间”并提醒。

---

## 📱 核心功能特性

- **三 Tab 架构**：
  - **重要（默认页）**：展示置顶旗标且未完成事项。
  - **进行中**：普通待办列表。
  - **已完成**：已归档待办，详情页可一键恢复。
- **动态日期分组与排序**：按开始时间就近排序，以「今天 / 明天 / 后天 / 日期」分组；过期未完成事项置灰标注。
- **三类提醒与调度**：
  - **固定提醒**：AlarmManager 精确到点推送（可设置提前量）。
  - **前置清单提醒**：开始前 3 小时自动核对未完成清单并推送。
  - **智能出发提醒**：结合实时位置与城市交通模型，在出发窗口期结合 30 分钟冷却状态机动态提醒。
- **地点与 POI**：高德 POI 检索与主流商圈枢纽，支持保存经纬度。
- **数据持久化**：本地单机存储，基于 Room 数据库，免登录开箱即用。

## 🚀 如何在 GitHub 下载 APK 安装包

本项目已内置 **GitHub Actions 自动化流水线（CI）**：

1. **进入 Actions 页面**：
   - 打开本 GitHub 仓库，点击顶部的 **Actions** 标签栏。
2. **选择构建记录**：
   - 点击最近一次名为 **Build Android APK** 的运行记录。
3. **下载 APK 产物（Artifacts）**：
   - 页面底部会显示名为 **`SmartTodo-Debug-APK`** 的文件，点击即可直接下载 zip 压缩包。
   - 解压后得到 `app-debug.apk`，发送到安卓手机即可直接点击安装运行！
